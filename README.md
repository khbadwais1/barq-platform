# منصة سقالات البرق

نظام عربي لإدارة بيع السقالات وتأجيرها لمؤسسة سقالات البرق — المدينة المنورة. يبدأ من عملية البائع وينتهي بفاتورة وتحصيل وقيد مالي ورصيد مخزون وعهدة لكل مشروع يمكن مراجعتها.

## نسخة العرض (للمراجعة)

**الرابط المباشر:** https://khbadwais1.github.io/barq-platform/

- ملف HTML واحد يعمل في المتصفح بدون خادم أو إنترنت: [`demo/barq-demo.html`](demo/barq-demo.html)
- الحسابات (كلمة المرور `2026`): `sulaiman` المالك، `finance` المالية، `seller1` و`seller2` البائعان، `yard` مسؤول العدد.
- البيانات تجريبية وتُحفظ في متصفح من يفتح الصفحة فقط. زر «إعادة البيانات للبداية» يرجعها.
- صفحة «سيناريوهات القبول» داخل النظام تشغّل 77 اختبارًا من المواصفات وتعرض نتيجتها.

### ما يغطيه العرض

| المجال | المحتوى |
|---|---|
| البيع | نقطة بيع للجوال، الحساب اللحظي، خصم بحد وموافقة المالك، فاتورة ضريبية برمز QR، سند استلام مواد |
| الإيجار | يومي/أسبوعي/شهري، مدة محددة أو مفتوح، تسليم، كشف دخول بحالة كل قطعة، فوترة بالقطعة × اليوم (الشهري ÷ 30، الأيام شاملة)، تأمين، إغلاق وإلغاء |
| العميل | بحث بخمسة مفاتيح، مشاريع متعددة، عهدة وذمة لكل مشروع، الكفيل الغارم، التقييم والقائمة السوداء، سند لأمر، كل السندات في ملف واحد |
| المالية | سندات القبض باسم المندوب، سندات الصرف، المصروفات وحد الاعتماد، الصندوق والبنوك، يومية الصندوق، الحركة الشهرية، دفتر الصندوق |
| اللوحات | المالك والمالية والبائع، بفترات «من / إلى» ومقارنة بالفترة السابقة |
| المستندات | قوالب بشكل أوراق المؤسسة، طباعة وتنزيل PDF لكل فاتورة وسند |

## هيكل المستودع

```
docs/            مراجعة المواصفات المصححة وصور النماذج الورقية الحالية
demo/            نسخة العرض: المصدر (src/) والاختبارات (test/) والملف المجمّع
prisma/          مخطط قاعدة البيانات PostgreSQL والترحيل الأول (النظام الكامل)
src/             تطبيق Next.js للنظام الكامل (قيد البناء)
scripts/         قاعدة PostgreSQL محلية للتطوير بدون Docker
```

## تشغيل نسخة العرض وتطويرها

```
npm install
cd demo
node build.mjs          # يجمع demo/src في demo/barq-demo.html
node test/smoke.cjs     # البيانات + اختبارات القبول + عرض كل صفحة لكل دور
node test/crawl.cjs     # يفتح كل صفحة ورابط وزر لكل دور
node test/fuzz.cjs 7    # 1500 عملية عشوائية مع التحقق من ترابط الأرقام
node serve.mjs          # معاينة على http://localhost:5180
```

## الحالة

- **نسخة العرض:** مكتملة للمراجعة مع العميل.
- **النظام الكامل (Next.js + PostgreSQL + Prisma):** المخطط والترحيل الأول جاهزان، والبناء متوقف حتى اعتماد ملاحظات العميل على العرض.
- **بنود تنتظر قرار المؤسسة:** موثقة في [`docs/01-SPEC-REVIEW.md`](docs/01-SPEC-REVIEW.md).
