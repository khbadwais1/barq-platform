# نسخة العرض — سقالات البرق

ملف HTML واحد (`barq-demo.html`) يُفتح بالمتصفح مباشرة بدون إنترنت أو خادم، ويُرسل للعميل للمراجعة.

- كلمة المرور لكل الحسابات: `2026` — `sulaiman` (المالك)، `finance` (المالية)، `seller1` و`seller2` (بائعون)، `yard` (مسؤول العدد).
- البيانات تُحفظ في متصفح من يفتح الملف فقط. زر «إعادة البيانات للبداية» يرجعها كما كانت.
- صفحة «سيناريوهات القبول» تشغّل اختبارات المواصفات (345، 138، التكرار، التزامن، الصلاحيات، المطابقة) على نسخة معزولة.

## التطوير

```
node build.mjs          # يجمع src/ في barq-demo.html
node test/smoke.cjs     # يولّد البيانات، يشغّل اختبارات القبول، ويعرض كل صفحة لكل دور
node test/crawl.cjs     # يفتح كل صفحة لكل دور ويتبع كل رابط ويتأكد أن لكل زر معالجًا
node test/fuzz.cjs 7    # 1500 عملية عشوائية مع التحقق من ترابط الأرقام بعد كل عملية
node serve.mjs          # معاينة على http://localhost:5180
```

قواعد العمل في `src/logic.js` هي نفس قواعد النظام الكامل (مبالغ بالهللة، أرصدة مشتقة من الدفاتر، مفاتيح طلب ثابتة).
